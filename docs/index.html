Capabilities

Every tool a
corpus linguist needs.

⟁
Frequency Analysis

Full word frequency tables with type/token ratios, sortable by raw count, lemma, or POS category.

◈
Concordance (KWIC)

Keyword-in-context concordance lines with adjustable span width and context export to Word or PDF.

◎
Lexicogrammatical Dispersion

Juilland's D and Gries' DP dispersion metrics computed across POS tags, lemmas, and phrases — a CorBas-original measure.

⬡
Collocation Networks

D3.js force-directed collocation graphs with MI-score and T-score weighting, spectral color coding, and zoom controls.

◻
Semantic Tagging

Integrated PyMUSAS USAS semantic tagger alongside spaCy POS and dependency parsing pipelines.

⬤
Exportable Results

Export annotated PDFs with highlights, Excel frequency tables, and Word concordance reports in one click.

Getting Started

Install on Windows.

CorBas is distributed as a standalone Windows desktop application. No Python installation required — the runtime is bundled in the release package.


A web-based version is under development and will be linked here when available. For academic inquiries or institutional licensing, contact corbas2026@gmail.com.

1
Download the latest release Visit the GitHub Releases page and download the .zip or installer for your system. github.com/mhdy54370-hub/CorBas-updates/releases
2
Extract & Launch Extract the archive, open the folder, and double-click CorBas.exe.
3
Load your corpus Use the Upload Corpus panel to load plain text (.txt) or PDF files and begin analysis.
4
Select an analysis tool Navigate the left panel to choose Frequency, Concordance, Dispersion, Collocations, or Semantic Tagging.
