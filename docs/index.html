CorBas is a corpus linguistic analysis tool developed by Muhammad Hussein Mahdi Mohsen at the University of Basrah. Available as a Windows desktop application for fully offline use — no data ever leaves your machine — and as a browser-based online edition accessible without installation. Both versions integrate spaCy POS tagging, PyMUSAS semantic analysis, dependency parsing, N-gram extraction, keyness metrics, and lexical dispersion plotting.

Part-of-Speech Tagging

CorBas uses spaCy's English model (`en_core_web_lg`) to tokenise and tag your texts automatically, labelling each word with the Universal Dependencies tagset and Penn Treebank equivalents.

Universal Tag Penn Treebank Equivalents Linguistic Description
PROPN NNP, NNPS Proper nouns (e.g., "Basra", "CorBas")
NOUN NN, NNS Common nouns (e.g., "linguist", "patterns")
VERB VB, VBD, VBG, VBN Main lexical verbs (e.g., "examined", "mapping")
DET DT, PDT Grammatical determiners (e.g., "the", "a")

Dependency Parsing

Syntactic dependency parsing maps the structural relationships between tokens in your corpus, showing how modifiers, subjects, and objects relate back to root predicates.

CorBas utilizes spaCy's dependency parser to compute full syntactic trees. This enables researchers to perform complex grammatical searches and map sentence patterns.

Dependency Tag Linguistic Relation Directional Example
nsubj Nominal Subject linguist ➔ examined
ROOT Root Lexical Verb examined
dobj Direct Object patterns ➔ examined
compound Noun Compound Modifier corpus ➔ patterns

PyMUSAS Semantic Analysis

By integrating the PyMUSAS semantic tagger, CorBas automatically assigns multi-tiered semantic codes based on the UCREL USAS taxonomy, grouping words into conceptual domains.

PyMUSAS categorizes tokens across 21 broad semantic domains (Cognition, Food, Time, Money, and others) and 253 specific sub-categories for systematic semantic investigation.

PyMUSAS Code Broad Domain Hierarchical Category Definition
Q2.1 Language Linguistic communication, writing, or speaking
Z2 Grammar Closed grammatical function words or closed class items
X2.4 Psychological Investigate, examine, analyze, cognitive research
P1 Education Educational settings, academic institutions

N-gram Analysis

N-grams extract sequences of N adjacent words from your corpus. This allows researchers to find formulaic patterns, fixed expressions, and recurrent collocations.

CorBas parses text using NLTK to extract bigrams, trigrams, 4-grams, and 5-grams, filtered by minimum frequency.

Keyness Significance & Effect Size

Keyness is "the statistically significantly higher frequency of particular words or clusters in the corpus under analysis in comparison with another corpus, either a general reference corpus, or a comparable specialized corpus" (Baker et al., 2008).

Log-Likelihood Formula: G² = 2 × ∑ ( O × ln(O / E) ) Where O represents Observed frequencies and E represents Expected values.

Lexical Dispersion Plot

Generate lexical dispersion plots to visualize how words are distributed across your corpus. The software calculates distributional metrics, including Juilland's D and Gries' DP, to help you identify whether a term is used consistently throughout the text or concentrated in specific sections.

Native Windows Standalone Execution

CorBas runs entirely offline as a local Windows desktop application — no data ever leaves your machine. There is no need to pre-install Python, configure virtual environments, manage spaCy models, or connect to external servers. The installer wizard configures everything automatically.

For educational institutional builds or customized corpus integration within departments and universities, contact the author directly at: corbas2026@gmail.com .

1
Download Desktop Setup Installer

Grab the latest offline executable package directly from the official GitHub updates repository.

github.com/mhdy54370-hub/CorBas-updates/releases
2
Run Installation Wizard

Open the standalone installer. The wizard configures all en_core_web_lg models, PyMUSAS tagsets, and NLTK databases automatically inside your local AppData directories.

3
Start Local Analysis

Launch CorBas using your desktop shortcut. Start loading plain text and PDFs, and generating publication-quality reports — with complete offline privacy.
